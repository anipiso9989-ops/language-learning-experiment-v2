# System (per language)
- **Vocabulary:** 6,000-word core list (self made)
- **Grammar:** concise comprehensive guide (self made)
- **Writing:** short stories in target language + AI correction (Gemini)
- **Speaking:** AI speaking/listening practice (Gemini, can't do until basic grammar/vocab is internalized)
- **Input:** native reading/listening (variety of sources online)

# Principle

Move through: **Unknown → Recognized → Retrievable → Usable → Automatic**

Gradually replace **English → target language** translation with **meaning → target language** production.

# Weekly Protocol

**Weekdays:** 15 min maintenance (do ≥2 of these sessions per language)
- Vocabulary practice
- Grammar review
- Occasional short writing

**Weekend:** 45-min sessions
- Saturday: Spanish + French writing
- Sunday: Norwegian writing + speaking practice (15 min per language)

Target: **~60 min/language/week**, with one rotating extra conversation session.

# Measurement

Track:
- Vocabulary retrieval
- Writing errors
- Speaking performance
- Listening comprehension

Maintain an **observation log** and use it to refine further practice.

# Core Loop

**Learn → Retrieve → Produce → Correct → Review → Repeat**
